# Worksheet: Binder Inventory

The shopping list and packing checklist for
[Your Own Enrollment Binder](../08-enrollment-binder.md). Hand this page
to a family helper, or use it yourself in one fifteen-minute sitting per
tab.

*Education and paperwork help only — never medical, legal, financial, or
plan advice.*

## Before you start

```
[ ] One 1.5-2 inch binder (or accordion folder)
[ ] 6 tab dividers, write-on kind
[ ] Sheet protectors for cards and precious letters
[ ] Pencil pouch: pens, sticky notes
[ ] Optional: scanner app or flatbed scanner for backups
```

## Tab 1 — Contacts

```
[ ] My plan's member-services number (from my card)
[ ] 1-800-MEDICARE written on one page
[ ] Social Security office (address + phone)
[ ] My SHIP office (address + phone)
[ ] My pharmacy (name + phone)
[ ] My helpers' names and numbers (family, power of attorney)
```

## Tab 2 — Current plan

```
[ ] Color copy of my current insurance card (card stays in my wallet)
[ ] This year's Summary of Benefits
[ ] This year's ANOC (Annual Notice of Change)
[ ] Formulary pages for my drugs
[ ] Provider directory pages for my doctors and hospital
```

## Tab 3 — Enrollment records

```
[ ] Enrollment confirmation letters (what I joined, and when)
[ ] Effective-date notices
[ ] Any penalty notice (read with the windows chapter)
[ ] Extra Help / MSP approval letters, if any
[ ] Medigap policy papers, if Door 1
```

## Tab 4 — Letters in and out

```
[ ] Every Medicare letter that arrived this year (oldest at back)
[ ] Copies of anything I mailed (disputes, exceptions, appeals)
[ ] Certified-mail receipts, if used
```

## Tab 5 — Money papers

```
[ ] Premium statements for the year
[ ] Payment confirmations
[ ] The yearly tax statement from Social Security
[ ] Drug receipts for the tax year
[ ] Financial-assistance paperwork (Extra Help, MSP, Medicaid)
```

## Tab 6 — Notes and worksheets

```
[ ] My Deadlines worksheet (filled)
[ ] Advantage or Supplement decision worksheet (filled)
[ ] Fine-Print Comparison worksheet (filled, dated)
[ ] Plan Call Notes log (running)
[ ] This inventory page
```

## The monthly fifteen minutes

```
[ ] Drop new papers into the right tab (filing only, no sorting)
[ ] Note anything missing on this page's back
[ ] Put the binder back in its home spot
```

## Privacy checklist (same rules as the binder chapter)

```
[ ] Card copy in the binder, card in the wallet, binder at home
[ ] No binder in the car, no card images in email
[ ] Old cards and expired papers: shred after replacements confirmed
[ ] Digital backups: offline folder on my own computer
```

*Education and paperwork help only — never medical, legal, financial, or
plan advice.*
