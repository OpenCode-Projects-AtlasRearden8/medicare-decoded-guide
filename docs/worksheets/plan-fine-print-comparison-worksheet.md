# Worksheet: Fine-Print Comparison

Side-by-side blanks for two candidate plans, built from
[Reading a Plan's Fine Print](../05-reading-fine-print.md). Fill every
cell from each plan's own Summary of Benefits and formulary — never from
ads or phone calls. If a cell can't be filled from the papers, that
itself is a finding.

*Education and paperwork help only — never medical, legal, financial, or
plan advice.*
